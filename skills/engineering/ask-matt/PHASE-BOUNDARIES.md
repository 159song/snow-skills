# 阶段边界（Phase boundaries）

**阶段（phase）**是会话内的一块工作：拷问、实现、QA。这个定义故意保持模糊：当你觉得*"好，这块做完了"*，一个阶段就结束了。

**阶段边界（phase boundary）**是两个阶段之间的间隙，也是这个决策唯一该发生的地方。阶段进行中没有决策可做：继续，或者把剩余的工作拆给 subagent。在阶段中途压缩上下文会让 agent 丢掉主线。

## 五个选项

| 选项       | 作用                                                    |
| ------------ | --------------------------------------------------------------- |
| **Continue（继续）** | 留在会话里，完全没有上下文切换。                    |
| **`/clear`** | 清空上下文窗口，从零开始。                  |
| **`/handoff`** | 写一个可移植的 markdown 文件，用它在任何地方播种一个新会话。 |
| **Subagent（子代理）** | 把任务送进它自己的上下文窗口，拿回一份报告。     |
| **`/compact`** | 压缩当前上下文，用摘要为新会话播种。  |

## 决策树

在边界处自上而下走。第一个**"是"**获胜。

**1. 能在当前会话里继续吗？** 两件事让答案为"是"：下一阶段需要把本阶段当作**一手来源（primary source）**，或者你剩余的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）还够装下下一阶段。拷问 → 实现是标准的"是"：实现想要的是原封不动的推理，而不是它的摘要。Continue 零成本、零损失，所以先在它身上做决断，再考虑其他任何选项。

**2. 上下文对接下来的事无关吗？** 本会话里的所有东西（探索、决策、死胡同）都是可丢弃的吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，交回整个窗口。`/clear` 也不是终点：旧会话仍然可以恢复。

做错这一步的代价是单向的。清掉一个*相关的*上下文，你就丢掉了你构建之物背后的**为什么**，把 diff 反复读多少遍也换不回来。

**3. 需要交接吗？** `/handoff` 的适用面很窄。只有当你：

- 切换到**新 harness**（Claude → Codex），
- 搬到**新目录**或仓库，
- 把工作发给**同事**，
- 或在**阶段中途**分叉出一个支线任务而不脱轨手头工作时，

才需要它。这份清单就是全部条款。`/handoff` 买到的是**可移植性**：一个能带走的文件。没有东西要转移，就不需要它。

**4. 任务能挂机完成吗？** 它的范围够紧，能在你离开键盘、无人掌舵的情况下运行吗？那就把它发给 **subagent**，让本会话原封不动。自动化 review 是标准场景：agent 读 diff、写报告，期间不需要你。

**5. 否则，`/compact`。** 相关上下文、同一 harness、同一目录，且你需要留在环里：决策树就落在这里，而且经常落在这里。给它传一条指令（`/compact 我们接下来要 QA 这块区域`），让摘要保住下一阶段需要的东西。

`/compact` 是**默认项，而不是第一选择**。它排在最底下，因为上面四个问题都更便宜或更精确。从这里起步的人的失败模式是：新会话对某个被摘要压平的决策自信满满地犯错。

## 一手来源与二手来源

除 **Continue** 之外的每一步动作都把**一手来源**变成**二手来源（secondary source）**：实际发生过的会话，被它的摘要取代。这笔交易永远是同一个形状：

| 来源                            | 信息 | 噪声 | 回旋余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（Continue）                | 完整        | 多    | 少       |
| 二手（`/compact`、`/handoff`） | 有损        | 少    | 多         |

这正是问题 1 排在最前面的原因。只有当留下的成本高于它省下的成本时，才支付这份有损。

## 这些是判断题

这些问题不是客观的：每一个都有品味成分，同一个边界在两天里可以走向两条不同的路。价值在于**按顺序**、在边界处问它们，而不是在工作的中途问。
