---
name: research
description: 对照高可信度的一手资料调研某个问题，并把发现以 Markdown 文件的形式记录到仓库中。当用户想让某个主题被调研、收集文档或 API 事实、或把阅读跑腿工作委托给后台 agent 时使用。
---

启动一个**后台 agent** 去做调研，这样它阅读的时候你可以继续干活。用全新的上下文窗口启动它。

它的职责：

1. 对照**一手资料**（官方文档、源代码、规范、第一方 API）调研问题，而不是二手转述。把每条主张追溯到拥有它的那个源头。
2. 把发现写入单个 Markdown 文件，为每条主张注明来源。
3. 保存到仓库已存放此类笔记的地方；遵循既有约定，如果没有约定，就放到一个合理的位置并说明放在哪。
