# Triage 标签（Triage Labels）

各 skill 以五个规范化 triage 角色来说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                                      |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                  |
| `needs-info`               | `needs-info`         | 等待报告者补充信息                       |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent               |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                             |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当某个 skill 提到某个角色时（例如「打上 AFK 就绪的 triage 标签」），使用本表中对应的标签字符串。

编辑「我们 tracker 中的标签」列，使其匹配你们实际使用的词汇。
