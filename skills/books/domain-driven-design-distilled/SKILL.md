# 《领域驱动设计精粹》（DDD Distilled，Vaughn Vernon）规则集

来自 [ciembor/agent-rules-books](https://github.com/ciembor/agent-rules-books)（MIT，冻结副本）。三档规则按需加载：

1. 默认先读并应用 [mini 版](domain-driven-design-distilled.mini.md)——包含本书的核心决策规则，多数任务足够。
2. 上下文预算紧张时改用 [nano 版](domain-driven-design-distilled.nano.md)。
3. 仅当 mini 规则不足以支撑当前权衡时，才把 [full 版](domain-driven-design-distilled.md)当深入参考查阅。
