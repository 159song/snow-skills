1. 默认先读并应用 [mini 版](clean-code.mini.md)——包含本书的核心决策规则，多数任务足够。
2. 上下文预算紧张时改用 [nano 版](clean-code.nano.md)。
3. 仅当 mini 规则不足以支撑当前权衡时，才把 [full 版](clean-code.md)当深入参考查阅。
