disable-model-invocation: true

每次调用先请用户选择讲解级别，即使用户在主题中提到了某种形式，也等用户确认后再开始。主题取自本次调用附带的问题或当前对话。

| 选项 | 说明 |
|---|---|
| L1 简明文本 | 用短句和例子理解概念或局部逻辑。 |
| L2 静态图解 | 沿着图中的箭头理解关系、顺序或数据流。 |
| L3 交互 HTML | 在页面上改变输入，观察结果如何变化。 |
| L4 讲解动画 | 通过连续画面观察变化过程或推导。 |

在 Claude Code 中调用 `AskUserQuestion`，标题用“讲解级别”，设 `multiSelect: false`。在 Codex 中使用当前模式可用且支持四个选项的提问工具（如 `request_user_input_async`），按工具的参数格式传入上表四项。两端都只问“这次想用哪种形式理解这个问题？”。

等待用户提交选择，再开始讲解或生成文件。当前模式无法一次显示四项时，把同样四项列为文本，请用户回复 L1–L4。取消或未作选择时，结束本次调用。

从命令参数或当前对话确定主题。选定级别后若主题仍不明确，问一句想理解什么。按所选级别交付：

1. **简明文本**。适合定义、差异和局部逻辑。先回答问题，再用一个具体输入或反例说明边界。
2. **静态图解**。适合组件关系、数据流和调用顺序。用 Mermaid 或 SVG 标出关键路径，说明读者应顺着哪条路径看。
3. **交互 HTML**。适合反复改变参数、对比结果。生成可本地打开的单文件页面，标明真实或示例数据，检查控件能否改变结果。
4. **讲解动画**。当连续变化本身就是理解难点时，用可用工具（如 Manim）渲染并检查动画。缺少渲染条件时，说明限制并提供关键帧图解。

生成文件后给出可访问的路径，说明用户应观察什么。将这次讲解限定在当前问题。
